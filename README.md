# CNI-Comparable-Orgs-Value-Proposition-Themes
A prototype exploration of the value and impact statements published by comparable organizations to CNI

This analysis was developed using Claude (Anthropic), and synthesizes value proposition language, impact statements, and outcomes-oriented assertions directly from each organization's public website, annual reports, and publications. Seventeen of the nineteen organizations publish formal VP or outcomes language; Code4Lib and CSG do not publish formal statements of this kind, and are noted accordingly.

Sixteen thematic dimensions were identified through iterative analysis of the collected data. Each organization's statements were coded against these themes, and the resulting matrix was used to generate the three views above. The spreadsheet, heatmap, and co-occurrence analysis were produced in a single session using Claude's code execution environment (Python/openpyxl for the spreadsheet; HTML/CSS/JavaScript for the interactive visualization).

This multi-tab exploration demonstrates the common themes of publicly available impact statements from 19 comparable organizations.

This exploraton was developed by pairing with Claude AI to develop html to represent the overlapping and distinct dimensions in value proposition statements. It is presented for exploration. It can be further developed with your feedback and suggestions. Please share those thoughts - and report errors - as pull requests!
